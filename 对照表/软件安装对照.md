# 常用软件三平台安装对照

同一软件在 Linux 各发行版、Windows、macOS 的安装方式汇总。

## 一、开发语言与运行时

| 软件 | Debian/Ubuntu | RHEL/Fedora | Arch | Alpine | macOS | Windows |
|------|---------------|-------------|------|--------|-------|---------|
| Python3 | `apt install python3 python3-pip` | `dnf install python3` | `pacman -S python` | `apk add python3 py3-pip` | `brew install python` | `winget install Python.Python.3` |
| Node.js | `apt install nodejs npm`（旧）/ nvm | `dnf install nodejs npm` | `pacman -S nodejs npm` | `apk add nodejs npm` | `brew install node` | `winget install OpenJS.NodeJS.LTS` |
| Go | `apt install golang-go` | `dnf install golang` | `pacman -S go` | `apk add go` | `brew install go` | `winget install GoLang.Go` |
| Java (JDK) | `apt install openjdk-17-jdk` | `dnf install java-17-openjdk-devel` | `pacman -S jdk17-openjdk` | `apk add openjdk17` | `brew install openjdk@17` | `winget install Microsoft.OpenJDK.17` |
| Ruby | `apt install ruby-full` | `dnf install ruby` | `pacman -S ruby` | `apk add ruby` | `brew install ruby` | `winget install RubyInstallerTeam.RubyWithDevKit` |
| PHP | `apt install php php-cli` | `dnf install php` | `pacman -S php` | `apk add php83` | `brew install php` | `winget install PHP.PHP` |

## 七、Windows 包管理器说明

| 工具 | 安装命令示例 | 特点 |
|------|--------------|------|
| **winget**（官方，Win10 1809+） | `winget install Git.Git` | 内置，推荐首选 |
| Chocolatey | `choco install git -y` | 生态老、包全，需管理员 |
| Scoop | `scoop install git` | 用户级安装、不污染 PATH，适合开发机 |

```powershell
# 检查 winget
winget --version

# 常用示例
winget install --id Git.Git -e
winget upgrade --id Git.Git -e
winget uninstall Git.Git
```

## 八、macOS 包管理器说明

| 工具 | 说明 |
|------|------|
| **Homebrew**（主流） | `brew install 包`，官网 https://brew.sh |
| MacPorts | `sudo port install 包`，较少用 |
| Xcode CLT | `xcode-select --install`（git、make 等基础工具） |

```bash
# 安装 Homebrew（官方）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

brew update
brew install git jq tree
brew upgrade
brew cleanup
```

## 九、脚本里做跨平台安装的示例

```bash
# 统一安装函数（配合 发行版适配/发行版检测.sh）
install_pkg() {
    case "$PKG_MGR" in
        apt)    sudo apt-get install -y "$@" ;;
        dnf)    sudo dnf install -y "$@" ;;
        yum)    sudo yum install -y "$@" ;;
        pacman) sudo pacman -S --noconfirm "$@" ;;
        apk)    sudo apk add "$@" ;;
        brew)   brew install "$@" ;;
        winget) winget install -e --id "$@" ;;
        *)      echo "不支持的包管理器"; return 1 ;;
    esac
}

install_pkg curl git jq
```

更完整的封装见本项目 `发行版适配/一键安装.sh`。
