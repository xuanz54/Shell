# Linux 发行版差异速查

同一脚本适配多发行版时需要关心的差异：包管理器、服务管理器、路径、命令别名。

## 一、发行版家族速查

| 家族 | 代表发行版 | 包管理器 | 配置工具 | 默认服务管理 |
|------|-----------|----------|----------|--------------|
| Debian 系 | Debian、Ubuntu、Linux Mint、Kali | `apt` / `dpkg` | `/etc/apt/` | systemd |
| RHEL 系 | RHEL、CentOS、Rocky、AlmaLinux、Fedora | `yum`（7）/ `dnf`（8+） | `/etc/yum.repos.d/` | systemd |
| SUSE 系 | openSUSE、SLES | `zypper` | `/etc/zypp/` | systemd |
| Arch 系 | Arch、Manjaro | `pacman` | `/etc/pacman.conf` | systemd |
| Alpine 系 | Alpine、postmarketOS | `apk` | `/etc/apk/` | OpenRC |
| Gentoo | Gentoo | `emerge` | `/etc/portage/` | OpenRC / systemd |
| 旧系统 | CentOS 6、Debian 7 | `yum` / `apt-get` | — | SysVinit / Upstart |

## 二、包管理器对照

| 操作 | apt (Debian) | dnf (Fedora/RHEL8+) | yum (RHEL7) | pacman (Arch) | apk (Alpine) | zypper (SUSE) |
|------|--------------|---------------------|-------------|---------------|--------------|---------------|
| 更新索引 | `apt update` | `dnf check-update` | `yum check-update` | `pacman -Sy` | `apk update` | `zypper refresh` |
| 安装 | `apt install -y 包` | `dnf install -y 包` | `yum install -y 包` | `pacman -S --noconfirm 包` | `apk add 包` | `zypper -n install 包` |
| 卸载 | `apt remove 包` | `dnf remove 包` | `yum remove 包` | `pacman -R 包` | `apk del 包` | `zypper -n remove 包` |
| 升级全部 | `apt upgrade -y` | `dnf upgrade -y` | `yum update -y` | `pacman -Syu --noconfirm` | `apk upgrade` | `zypper -n update` |
| 搜索 | `apt search 关键字` | `dnf search 关键字` | `yum search 关键字` | `pacman -Ss 关键字` | `apk search 关键字` | `zypper search 关键字` |
| 查已装 | `dpkg -l \| grep 包` | `dnf list installed 包` | `rpm -qa \| grep 包` | `pacman -Q 包` | `apk info 包` | `rpm -qa` |
| 清缓存 | `apt clean` | `dnf clean all` | `yum clean all` | `pacman -Sc` | — | `zypper clean` |
| 本地 deb/rpm | `dpkg -i xx.deb` | `dnf install xx.rpm` | `yum install xx.rpm` | `pacman -U xx.pkg.tar*` | `apk add xx.apk` | `zypper in xx.rpm` |

## 三、服务管理器对照

### systemd（主流：Ubuntu 16.04+、CentOS 7+、Debian 8+）

```bash
systemctl status 服务名      # 状态
systemctl start|stop|restart 服务名
systemctl enable|disable 服务名   # 开机自启
systemctl list-units --type=service
journalctl -u 服务名 -f       # 该服务日志
```

### OpenRC（Alpine、Gentoo 默认）

```bash
rc-service 服务名 status
rc-service 服务名 start|stop|restart
rc-update add 服务名 default   # 开机自启
rc-update del 服务名
rc-status
```

### SysVinit（旧系统：CentOS 6、Debian 7）

```bash
service 服务名 status|start|stop|restart
chkconfig 服务名 on|off       # 开机自启（RHEL 系）
update-rc.d 服务名 enable     # 开机自启（Debian 系）
```

### Upstart（Ubuntu 14.04、CentOS 6 部分）

```bash
initctl status 服务名
start|stop|restart 服务名
```

### 通用检测片段（可 source）

```bash
if command -v systemctl >/dev/null 2>&1 && [ -d /run/systemd/system ]; then
    SVC_MGR=systemd
elif command -v rc-service >/dev/null 2>&1; then
    SVC_MGR=openrc
elif command -v service >/dev/null 2>&1; then
    SVC_MGR=sysv
else
    SVC_MGR=unknown
fi
```

也可直接使用本项目：`发行版适配/服务管理对照.sh`。

## 四、关键文件路径差异

| 内容 | Debian/Ubuntu | RHEL/CentOS | Arch | Alpine |
|------|---------------|-------------|------|--------|
| 主机名 | `/etc/hostname` | `/etc/hostname` | `/etc/hostname` | `/etc/hostname` |
| hosts | `/etc/hosts` | `/etc/hosts` | `/etc/hosts` | `/etc/hosts` |
| DNS | `/etc/resolv.conf` | `/etc/resolv.conf` | `/etc/resolv.conf` | `/etc/resolv.conf` |
| 网络配置 | Netplan `/etc/netplan/` | `/etc/sysconfig/network-scripts/` 或 NetworkManager | `/etc/systemd/network/` | `/etc/network/interfaces` |
| 防火墙默认 | ufw（可选） | firewalld | iptables/nftables | iptables |
| 默认 shell | bash | bash | bash | ash (busybox) |
| 日志目录 | `/var/log/` | `/var/log/` | `/var/log/` | `/var/log/` |
| 认证日志 | `/var/log/auth.log` | `/var/log/secure` | `/var/log/auth.log` | `/var/log/auth.log`（需配置） |
| 包列表导出 | `dpkg --get-selections` | `rpm -qa` | `pacman -Qq` | `apk info -v` |

## 五、命令差异（同名不同义或缺失）

| 功能 | Debian/Ubuntu | RHEL/CentOS | 说明 |
|------|---------------|-------------|------|
| 主机发行版信息 | `lsb_release -a`（需装包） | `cat /etc/redhat-release` | 最稳妥：`cat /etc/os-release` |
| 防火墙 | `ufw status` | `firewall-cmd --list-all` | 两者都基于不同后端 |
| 静态 IP | Netplan `netplan apply` | `nmcli` 或改 ifcfg | 语法完全不同 |
| DNS 解析 | `resolvectl` / `systemd-resolved` | `resolvectl` | — |
| 时间同步 | `timedatectl` | `timedatectl` | systemd 统一 |
| 内核参数 | `sysctl -p` | `sysctl -p` | 参数名一致 |
| useradd 参数 | 相同 | 相同 | RHEL 默认创建用户会拷 skel |

### busybox 差异（Alpine/路由器）

很多命令是 busybox 精简版：
- `ping`、`wget`、`grep`、`sed` 功能子集
- 无 `ss`（除非装 iproute2）
- 无 `systemctl`（用 OpenRC）
- 脚本应避免 GNU 独有参数（如 `sed -i` 无后缀在 busybox 可用，但 `grep -P` 不可用）

## 六、版本判断片段

```bash
# /etc/os-release 各发行版均支持（systemd 时代）
. /etc/os-release 2>/dev/null
echo "$ID $VERSION_ID"          # 例如: ubuntu 22.04
echo "$ID_LIKE"                 # debian rhel fedora 等

# 包管理器检测
if   command -v apt-get >/dev/null; then PKG=apt
elif command -v dnf     >/dev/null; then PKG=dnf
elif command -v yum     >/dev/null; then PKG=yum
elif command -v pacman  >/dev/null; then PKG=pacman
elif command -v apk     >/dev/null; then PKG=apk
elif command -v zypper  >/dev/null; then PKG=zypper
fi
```

完整封装见 `发行版适配/发行版检测.sh`。

## 七、写跨发行版脚本的建议

1. 以 `/etc/os-release` 判断，不猜 `uname`
2. 包安装统一走函数：`pkg_install 包1 包2`（内部按 `$PKG` 分支）
3. 服务操作统一走函数：`svc_restart 服务名`
4. 日志路径做双探测：`auth.log` 不存在则读 `secure`
5. 避免 GNU 专有命令参数；需要时检测 `command -v gsed`
6. 在 Alpine 上测试 busybox 兼容性
