# 跨平台命令对照表（Linux ↔ Windows ↔ macOS）

常用运维/开发命令在三大平台的对应关系。Windows 列优先给出 PowerShell 命令（Win10+ 内置），部分附 CMD。

## 系统信息

| 场景 | Linux | Windows (PowerShell) | macOS |
|------|-------|----------------------|-------|
| 系统版本 | `cat /etc/os-release` | `Get-CimInstance Win32_OperatingSystem` | `sw_vers` |
| 内核/版本 | `uname -a` | `Get-CimInstance Win32_OperatingSystem \| Select Version` | `uname -a` |
| 主机名 | `hostname` | `hostname` | `hostname` |
| 运行时间 | `uptime` | `(Get-CimInstance Win32_OperatingSystem).LastBootUpTime` | `uptime` |
| CPU 型号 | `lscpu` / `cat /proc/cpuinfo` | `Get-CimInstance Win32_Processor` | `sysctl -n machdep.cpu.brand_string` |
| CPU 核数 | `nproc` | `$env:NUMBER_OF_PROCESSORS` | `sysctl -n hw.ncpu` |
| 详细硬件 | `dmidecode`（需 root） | `Get-CimInstance Win32_ComputerSystem` | `system_profiler SPHardwareDataType` |

## 文件操作

| 场景 | Linux/macOS | Windows (PowerShell) |
|------|-------------|----------------------|
| 复制 | `cp -a 源 目标` | `Copy-Item 源 目标 -Recurse` |
| 移动/重命名 | `mv 源 目标` | `Move-Item 源 目标` |
| 删除 | `rm -rf 路径` | `Remove-Item 路径 -Recurse -Force` |
| 查找文件 | `find / -name "*.log"` | `Get-ChildItem -Recurse -Filter *.log` |
| 查找内容 | `grep -r "关键字" 目录` | `Select-String -Path 目录\* -Pattern 关键字 -Recurse` |
| 权限 | `chmod 755 文件` | ACL：`Get-Acl` / `icacls`（语义不同） |
| 属主 | `chown 用户:组 文件` | 所有权：`Get-Acl`（域/用户组体系不同） |
| 软链接 | `ln -s 源 目标` | `New-Item -ItemType SymbolicLink`（需开发者模式/管理员） |
| 硬盘挂载 | `mount /dev/sdb1 /mnt` | `Mount-Volume` / `diskpart` |
| 查看文件 | `cat` / `less` | `Get-Content` / `notepad` |

## 常见差异坑

1. **路径分隔符**：Linux/macOS 用 `/`，Windows 用 `\`（PowerShell 中也可用 `/`）
2. **大小写**：Linux/macOS 文件系统默认区分大小写，Windows 不区分；macOS APFS 默认不区分但可配置
3. **行尾符**：Linux LF、Windows CRLF，脚本跨平台传输建议 `dos2unix` 或 git 配 `core.autocrlf`
4. ** shebang**：`.sh` 用 `#!/usr/bin/env bash`；`.ps1` 无需 shebang，用 `powershell -File` 或 `pwsh -File` 运行
5. **权限模型**：Unix 是 rwx + 属主/属组/其他人；Windows 是 ACL，不能简单对应 `chmod`
6. **包管理器**：见上表，没有统一命令，建议脚本里先检测发行版（见 `发行版适配/发行版检测.sh`）
7. **服务管理**：现代 Linux 用 systemd，旧系统/Alpine 可能是 OpenRC/SysV；macOS 用 launchd；Windows 用 SCM
